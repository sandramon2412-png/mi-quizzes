API de Groq (para tus quizzes y mini-apps publicados)

La plataforma cubre la IA para crear tus quizzes y mini-apps. Tu Groq API key se usa solo cuando tus visitantes interactúan con chatbots o generadores dentro de tus mini-apps publicadas. Es gratis y sin límite práctico.

menu_book

Cómo obtener tu API key de Groq (2 minutos)

  1. 1
    Entra a console.groq.com/login y crea una cuenta gratis (con Google o email).
  2. 2
    Ve a console.groq.com/keys y haz clic en "Create API Key".
  3. 3
    Dale un nombre (ej: "Luminous Studio") y copia la clave que empieza con gsk_...

    Importante: solo podrás ver la clave una vez. Cópiala de inmediato.

  4. 4
    Pégala en el campo de abajo y haz clic en "Guardar API Key". Luego prueba la conexión.

info Es 100% gratis. Groq ofrece 30 peticiones/min y millones de tokens al mes, suficiente para miles de interacciones de tus clientes al mes.

psychology ¿Para qué se usa? Para las secciones de Chatbot y Generador con IA dentro de tus mini-apps, cuando tus compradores las utilicen. La creación de contenido (quizzes, apps, Bot Lab, asistente Lloyd) la cubre la plataforma.

lock Tu clave es tuya. Se guarda encriptada en tu cuenta y nunca la compartimos. Solo tú la usas.

help ¿Tienes problemas? Puedes ver la documentación oficial.

Formato: empieza con gsk_ seguido de una cadena larga.

Pasos para conectar tu dominio

  1. 1

    Entra a tu proveedor de dominio

    GoDaddy, Namecheap, Google Domains, etc.

  2. 2

    Agrega un registro CNAME

    Nombre: quiz (o el subdominio que prefieras)

    Valor: cname.vercel-dns.com

  3. 3

    Escríbenos con tu dominio

    Nosotros lo activamos en Vercel en menos de 24h. Tu quiz quedará en quiz.tu-dominio.com

Una vez configurado el CNAME, escribe aquí tu dominio completo.
